Two collections go in.
A ready-to-fill form comes out.

Think of columns as the recipe and case records as the harvest. JSON Renderers Build cooks them into a form spec and linked suggestion lists. JSON-to-tag serves that spec as the live form below.

ℹThis example reads data.json, a JSON array of records. It is not a JSONL file.

Write the recipe

columns.json

Six column definitions name the fields. Five carry a dataListId to ask for suggestions.

02

Gather the harvest

data.json

Each record is a case. Matching column values become the ingredient pool for suggestions.

03

Let Build cook

JSON Renderers Build

The shared form renderer creates the vertical form and deduplicated datalist nodes, linked by IDs.

04

Serve the result

JSON-to-tag

buildSpecElement(spec) turns Build's JSON spec into the browser DOM.
