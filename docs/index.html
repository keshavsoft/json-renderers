v22 · Browser DOM Mounting Runtime

Pass data & columns.
Get a live component on the page.

json-renderers is one function — render(config) — that accepts a plain object, builds a component spec, converts it to DOM nodes, and mounts it into your target HTML element.

The Core Story

The Input Contract

Everything you send into render() falls into two clear groups.

📋

Group 1 — Spec

What to build

Describes which component to render and what data to populate it with. This group is handed to json-renderers-specs to produce the JSON AST.

type string

Which component to render.
"table.simple" | "form" | "select" | "dataList" | "searchInput"

data Array

Your data records — array of row objects.

columns Array

Column definitions — schema, labels, types, widths, placeholders.

options object

Feature flags for the component.
showSerial · showSearch · showOptions · title · submitLabel · label · placeholder

showLog boolean

Logs internal spec and DOM steps to the console. Default: false

📍

Group 2 — Mount

Where to put it

Describes where in the DOM to place the rendered component and how to place it. This group is used directly by json-renderers when mounting.

targetHtmlId string

The id of the HTML element to mount into.
Internally: document.getElementById(targetHtmlId)

classToApply string

A CSS class added to the rendered root element. Pass "" to skip.

appendPosition string

How to place the component inside the target container.
"replace" — clears the container and replaces its content.
"prepend" — inserts before existing content.

Live Sample · tableWithSearch

The Full Call — Annotated

// samples/v22/tableWithSearch/index.js

window.ks.jsonRenderers.render({

  // ── SPEC: what to build ───────────────────────────
  type: "table.simple",
  data: data,            // ← your row objects array
  columns: columns,         // ← your column definitions array
  options: {
    showSerial: true,    // adds a # serial column
    showSearch: true,    // adds a live search bar
    showOptions: true,    // adds a row-level action button
  },
  showLog: false,

  // ── MOUNT: where to put it ────────────────────────
  targetHtmlId: "dom-render-container",
  classToApply: "",
  appendPosition: "replace",

});
Component Types

What Can You Render?

📊 table.simple

Simple Table

Data table with headers and rows. Use showSerial, showSearch, showOptions flags.

📝 form

Form

Input form, fields from columns, pre-filled from data[0]. Options: title, submitLabel.

▣ select

Select Dropdown

Dropdown auto-targeted to the select-type column in your schema.

🔍 dataList

DataList Autocomplete

Native browser autocomplete input, populated from your data.

🔎 searchInput

Search Input

Standalone search bar. Options: label, placeholder.

🌐 Global Registration

When loaded via <script type="module">, the renderer is available on the global namespace:

window.ks.jsonRenderers = {
  meta: { version: "1.22.1" },
  render: [Function]
};
