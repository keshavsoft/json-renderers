📋 Doc 2 · The Contract

The Input Contract

When you call render(config), you pass one plain JavaScript object. That object has a clear contract — every field is known, validated, and purposeful.

The contract splits cleanly into two groups: what to build, and where to put it.

📋
Group 1 — Spec
What to build
typestring
Which component to render.
"table.simple" "form" "select" "dataList" "searchInput"
dataArray
Array of row objects. Each object is one data record. See Doc 3 for full shape.
columnsArray
Array of column definition objects — schema, labels, types, widths. See Doc 3 for full shape.
optionsobject
Feature flags per component type.
showSerial showSearch showOptions title submitLabel label placeholder
showLogboolean
Log internal spec and DOM steps to the browser console. Default: false
📍
Group 2 — Mount
Where to put it
targetHtmlIdstring
The id of the HTML element to mount the component into.
Internally: document.getElementById(targetHtmlId)
classToApplystring
A CSS class name applied to the rendered root element. Pass "" to skip.
appendPositionstring
How to place the component inside the target container.
"replace" — clears the container, then inserts.
"prepend" — inserts before any existing content.

The guard library (json-renderers-guard) validates both groups before anything is built. If a required field is missing or has the wrong type, it throws clearly — before any DOM work begins.

The Full Annotated Call

Here is every field of the contract in one real call, with both groups labeled:

window.ks.jsonRenderers.render({

  // ── Group 1: SPEC — what to build ────────────────
  type:    "table.simple",
  data:    data,             // array of row objects
  columns: columns,          // array of column definitions
  options: {
    showSerial:  true,      // add a # serial column
    showSearch:  true,      // add a live search bar
    showOptions: true,      // add a row action button
  },
  showLog: false,

  // ── Group 2: MOUNT — where to put it ─────────────
  targetHtmlId:   "dom-render-container",
  classToApply:   "",
  appendPosition: "replace",

});
