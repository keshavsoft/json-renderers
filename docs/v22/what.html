🎯 Doc 1 · The Idea

What Are We Doing?

You have data — a list of records.
You have columns — a schema that describes those records.
You want a live UI component — a table, a form, a dropdown — rendered right into your browser page.

json-renderers is the single function that makes that happen.

The Core Flow

Three things go in. One live DOM component comes out.

📦 Your Input
data + columns + where to put it
↓
🖥️ json-renderers
render(config) — one function call
↓
🌐 Live Browser DOM
<table>, <form>, <select> ... mounted in your page
The One-Line Summary

You call render(config) and a fully built HTML component appears inside your chosen HTML element. That is the entire job.

A Simple Analogy

Think of it like placing an order at a restaurant:

📝
You place the order
You say: "I want a table, here's my data, here's my schema, put it in this div."
🍳
The kitchen cooks it
Internally the system validates, builds a spec, and creates the DOM elements.
🍽️
It arrives at your table
The finished component is mounted right into the target element on your page.

The Minimum Call

This is all you need to get a table on the page:

window.ks.jsonRenderers.render({
  // What to build
  type:    "table.simple",
  data:    data,     // your records
  columns: columns,  // your schema

  // Where to put it
  targetHtmlId: "my-container"
});

That single call produces a fully rendered, styled table — with headers from your columns and rows from your data — and places it inside #my-container.
