🧩 Doc 5 · Component Types

What Can You Render?

The type field in your config decides which component is built. The same data and columns you defined once can produce any of these components — you just change the type.

📊
table.simple
Data table with headers and rows

Renders a full HTML table. Headers come from your columns[].label. Rows come from your data array. Each cell maps a data key to a column via columnName. Use options to add extra features.

options flags

showSerial — adds a # column showSearch — adds a live search bar showOptions — adds a "show" action button per row 
window.ks.jsonRenderers.render({
  type:    "table.simple",
  data, columns,
  options: { showSerial: true, showSearch: true, showOptions: true },
  targetHtmlId:   "my-container",
  appendPosition: "replace"
});
📝
form
Input form, schema from columns, values from data

Renders a complete input form. Each column becomes one form field — its type determines the input kind (text, select, checkbox, textarea). The first data record (data[0]) pre-fills the values.

options flags

title — form heading text submitLabel — text on the submit button 
window.ks.jsonRenderers.render({
  type: "form",
  data, columns,
  options: {
    title:       "Edit Product Record",
    submitLabel: "Save Item"
  }
});
▣
select
Dropdown — auto-targets the select-type column

Renders a <select> dropdown. It automatically finds the column in your columns array that has type: "select" and uses its options array as the dropdown choices. No extra configuration needed.

options flags

No extra options needed — auto-targets select column 
window.ks.jsonRenderers.render({
  type: "select",
  data, columns
  // automatically picks "category" column (type: "select")
});
🔍
dataList
Native browser autocomplete input

Renders a native browser <datalist> linked to an <input>. As the user types, the browser shows matching suggestions drawn from your data. Auto-targets the first text-type column.

options flags

No extra options needed — auto-targets text column 
window.ks.jsonRenderers.render({
  type:          "dataList",
  data, columns,
  targetHtmlId:   "my-container",
  appendPosition: "replace"
});
🔎
searchInput
Standalone search bar with label

Renders a standalone search <input> with an optional label. Useful when you want to separately render a search bar and connect it to a table or list programmatically.

options flags

label — text label above the input placeholder — placeholder text inside the input 
window.ks.jsonRenderers.render({
  type: "searchInput",
  data, columns,
  options: {
    label:       "Filter Inventory:",
    placeholder: "Search item, category, or rate..."
  }
});
